# Examples

End-to-end usage of MaSC on a single sample.

## `sample_hat/`

A DreamBench++-style sample. The reference is a single-concept photo of
a hat; the output was generated by `ip-adapter` (vit-giant SDXL,
`scale=0.6`, `gs=7.5`, 100 steps, seed 42, fp16). Both masks are from
SAM3.

```
sample_hat/
├── reference.jpg        the concept reference image
├── reference_mask.png   SAM3 binary mask of the concept (hat) in the reference
├── output.jpg           the generated image
├── output_mask.png      SAM3 binary mask of the concept in the output
└── prompt.txt           line 1: subject name | line 2: full prompt
```

## Run

```bash
pip install masc-metric
python examples/score_sample.py
```

You will need:

- A CUDA-capable GPU (or set `device="cpu"` in the script — slow).
- HuggingFace access to `google/siglip2-so400m-patch16-naflex`. Accept
  the model license on the HF page and run `huggingface-cli login`.
